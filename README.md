# Brilliads Agency Website

Professional website for Brilliads Agency - Advertising, Marketing & Manpower Solutions.

## Project Structure

```
briliads-agency-website/
├── index.html              # Main homepage
├── css/
│   ├── style.css          # Custom styles
│   └── responsive.css     # Responsive design rules
├── js/
│   ├── main.js            # Main JavaScript functionality
│   ├── animations.js      # Animation handlers
│   └── utils.js           # Utility functions
├── assets/
│   ├── images/
│   │   ├── logo.png
│   │   ├── hero-bg.jpg
│   │   └── products/
│   │       ├── product1.jpg
│   │       ├── product2.jpg
│   │       └── service1.jpg
│   └── icons/
│       └── favicon.ico
├── pages/
│   ├── services.html      # Detailed services page
│   ├── about.html         # About us page
│   ├── portfolio.html     # Portfolio/Gallery page
│   └── contact.html       # Contact form page
└── .gitignore
```

## Features

✨ Modern, responsive design
🎨 Gold & dark theme branding
📱 Mobile-friendly navigation
🎯 WhatsApp integration
✅ Smooth scroll animations
🏢 Multi-page structure

## Tech Stack

- **HTML5** - Semantic markup
- **CSS3** - Custom styling + Tailwind CSS
- **JavaScript** - Interactive features
- **AOS** - Scroll animations
- **Font Awesome** - Icons

## Getting Started

1. Clone the repository
2. Open `index.html` in your browser
3. Customize images, text, and colors as needed
4. Update contact information
5. Deploy to your hosting

## Customization

- Replace placeholder images in `assets/images/`
- Update contact details in footer
- Modify colors in `css/style.css`
- Add more services in `pages/services.html`
